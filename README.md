# 🎬 StreamFlix AI

An AI-powered streaming platform concept that combines modern web technologies with Generative AI to create an intelligent movie discovery experience.

---

## 🚀 Live Demo

https://streamflix-ai.vercel.app

---

## ✨ Features

- 🎥 Browse trending movies
- 🤖 AI-powered movie recommendations
- 🔍 Smart search experience
- 📱 Fully responsive UI
- ⚡ Fast performance
- 🎨 Modern Netflix-inspired design

---

## 🛠 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- TMDB API
- Google Gemini AI
- REST API
- Vercel
